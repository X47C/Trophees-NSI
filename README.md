# Darwined

Simulateur d'évolution simlifiée sur la base de la séléction naturelle, ayant pour objectif d'observer l'évolutions de différentes caractéristiques chez un ou plusieurs groupes d'individus dans differentes situations.

## Pour commencer

Il est conseillé de regarder le tutoriel affiché lors du premier démarage du jeu, sinon, rien d'autre n'est requis !

### Pré-requis

Dans le répertoire sources:

- Pygame/button.py
- Pygame/food_editor.py
- Pygame/pygame.py
- Pygame/toolbox.py
- Game/creature.py
- Game/food.py
- Game/game.py
- main.py
- settings.py

### Installation

Il faut tout d'abord installer python. Il faut ensuite installer les differentes librairies, à l'aide de la commande "pip install" dans l'invite de commannde.  

## Démarrage

Vous devez executer le  fichier main.py

## Fabriqué avec

Pygame, MatplotLib, opencv-python
